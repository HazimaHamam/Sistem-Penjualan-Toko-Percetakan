# Sistem Penjualan Toko Percetakan

Sistem informasi penjualan berbasis Laravel yang dilengkapi fitur prediksi penjualan menggunakan Machine Learning.

## Fitur
- Dashboard penjualan
- Manajemen produk
- Manajemen transaksi
- Prediksi penjualan
- Laporan penjualan

## Teknologi
- Laravel
- MySQL
- Python Machine Learning
- Chart.js
